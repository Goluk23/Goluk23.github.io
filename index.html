HTML

  • ICONE NAVIGATEUR

    Chercher logo HTML -> Images -> Outils -> Couleur -> Transparent

    Pour l'ajouter aller sous title -> taper link (link rel="stylesheet" href="") apparait -> remplacer "stylesheet" par "shortcut icon" et indiquer son chemin dans href="./..."

    Exemple: link rel="shortcut icon" href="./assets/img/logo.png"

  • LES DIFFERENTES PARTIES D'UN SITE

    Principales: nav header main footer

    Secondaires: section div span p i

  • UL = Unordered List -> liste sans numéro (avec des puces)

    Utilisation "UL" -> "LI" pour les élements à lister (possibilité d'utiliser li*# où # = nombres de répetitions de LI)

  • OL = Ordered List -> Liste avec des numéros

    Utilisation "OL" -> "LI" pour les élements à lister (possibilité d'utiliser li*# où # = nombres de répetitions de LI)

  • IMAGE EN HTML

    Utiliser "img" qui donne (img src="" alt="") indiquer son chemin dans src="./..." et indiquer une description dans alt="".

    Utilisation de height="200" par exemple est possible pour réduire sa taille en HTML

  • TYPE DE TEXTE

    Normal

    Italique balise "em"

    Gras balise "strong"

    Faux texte en latin "lorem#" où # = nombre de mots à ajouter

  • UTILISATION DES TABLEAUX

    Utilisation: table border="#" et "cellpading="#"" pour créer un espacement à l'intérieur des cellules et ajouter "cellspacing="#"" pour l'espacement entre cellules

    Exemple: table border="1" cellpadding="10" cellspacing="3" style="text-align: center"

    Utiliser "thead" pour l'entête du tableau Utiliser "tr" pour définir la ligne de l'entête Utiliser "th" pour chaque colonne de l'entête
    Utiliser "tbody" pour la suite du tableau Utiliser "tr" pour chaque ligne du tableau Utiliser "td" pour chaque colonne du tableau
    Utiliser "tfoot" pour le pied du tableau avec "tr" et "td" Utiliser "rowspan="#"" ou "colspan="#"" pour étendre une cellule

  • UTILISATION DES LIENS

    • Lien vers un autre site

      Taper "a" (pour ancre) remplir href="" et remplir par un texte entre les balises

      Utiliser "target="_blank"" pour ouvrir dans un nouvel onglet

      Exemple: dans les balises a: href="https://htmlcheatsheet.com/" target="_blank">HTML Cheat Sheet

      HTML Cheat Sheet

    • Lien vers une autre partie du site

      Créer un id à la section vers laquelle on veut créer un lien

      Utiliser une ancre a dans href="#id" où id est l'id est celui de la section désirée.

      Exemple: retour vers HTML

    • Lien vers un Email

      Utiliser l'ancre a avec dans href="mailto:adresse@domain.ext" suivi du message du lien.

      Contactez-moi

    • Lien vers un téléchargement

      Utiliser l'ancre a avec dans href="./assets/documentaenvoyer.txt" suivi de (download="documentaenvoyer")> Nom du lien.

      Exemple: télécharger la notice

  • INTEGRATION DES VIDEOS

    • Vidéos et images gratuites et libres de droits -> pixabay https://pixabay.com/fr/

      Utiliser "Video" remplir la src:".//"

      Paramètres à utiliser: "autoplay" "muted" "loop" et éventuellement "height="200"

      Exemple: video src="./assets/video/video.mp4" height="200" autoplay muted

  • LES FORMULAIRES

    • Input de type text

      Délarer avec la balise "form" action="" peut rester libre pour l'instant.

      Ensuite déclarer un "label" avec for="id de l'input" suivi du texte a afficher.

      Déclarer enfin un "input" de type "text" et dans "id" utiliser la même chose que dans label pour lier les deux.

      On peut tuiliser un placeholder="entrez votre texte"

    • Input de type number

      Délarer avec la balise "form" action="" peut rester libre pour l'instant.

      Ensuite déclarer un "label" avec for="id de l'input" suivi du texte a afficher.

      Déclarer enfin un "input" de type "number" et dans "id" utiliser la même chose que dans label pour lier les deux.

      On peut utiliser value="18" par exemple pour commecer avec un nombre.

    • Input de type select

      Déclarer un "label" avec for="id de l'input" suivi du texte a afficher.

      Déclarer "select" et dans "id" utiliser la même chose que dans label pour lier les deux.

      Dans "select" déclarer "option" pour chaque option remplir la value et le texte à afficher.

      Rajouter la banière selected="selected" devant "value" pour l'option par défaut.

    • Input de type radio

      Déclarer input de type radio avec le même "name" pour tous les "radio" liés et même id pour chaque choix différent.

      Déclarer un "label" avec for="id de l'input" suivi du texte a afficher.

      Copier le nombre de fois que nécessaire input et label avec le même name et id différent à utiliser dans label.

      On peut utiliser la balise "checked" après id pour qu'il soit selcetionné par défaut.

    • Input de type textarea

      Déclarer "textarea" on peut effacer "name=" et "id=".

      On peut rajouter "placeholder" pour afficher du texte dans la box.

      On peut rajouter "cols=#" et "rows=#" pour la taille de la textarea.

    • Input de type checkbox

      Déclarer un input de type checkbox on peut laisser le name vide.

      Déclarer un "label" avec for="id de l'input" suivi du texte a afficher.

    • Bouton pour valider

      Déclarer un input de type submit et mettre dans value ce qu'on veut affficher.

    • Pour que les différents boutons soient liés avec l'envoi il faut qu'ils soient dans la même balise "form".

CSS

  • Créer un fichier style.css dans l'arborescence d'index.html

    Intégrer une page CSS à Index.html

    En dessous de la balise Title mais toujours dans HEAD rajouter la balise CSS.

    Il faut rajouter la balise link:css et pointer vers le fichier CSS.

    Exemple: link rel="stylesheet" href="/.style.css"

    Vérifer que le lien est présent en ajoutant body puis background=red pour vérifier que le body est rouge.

    Exemple: body {background: red;}

  • Utilisation de CSS sur H1 (en considérant que c'est le seul H1 de la page)

    • text-transform

      text-transform: capitalize; -> Première lettre en Majuscule
      text-transform: uppercase; -> Toutes les lettres en Majuscule

    • letter-spacing & font-size

      letter-spacing: #px; -> Espace entre les lettres en pixels (px)
      text-align: center; -> Aligner le texte au mileu de la ligne
      font-size: 1rem; -> Taille du texte 1 rem (1rem = 16px)

    • text-shadow

      text-shadow: 0 0 0 black; -> définis pas d'ombre noire -> aller dans inspecter -> text-shadow -> définir l'ombre voulue et récupérer le code, sur couleur choisir l'opacité (recommandé à +/-25%).

      Exemple: text-shadow: 3px 3px 8px #00000042;

    • color

      color:black par exemple

      On peut aussi utiliser les couleurs en rgba(255,255,255,1) r = rouge, g = vert, b = bleu, a = opacité ( 1= full).

      Autres couleurs evec #eeeeee par exemple (#000000 = noir).

    • font-family

      Soit les polices fournies par CSS

      Exemple: font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;

      Soit sur Google Fonts
      -> Soit copier le lien vers les fonts au début du CSS

      Exemple: @import url('https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,100..900;1,100..900&display=swap');

      -> Soit les télécharger

      Puis les déclarer dans le CSS avec fontface {font-family:"NomPolice"; src: url (./)}

      Exemple: @font-face {font-family: "Poppins";src: url(./assets/fonts/Poppins-Medium.ttf);}

    • background

      Changement de couleur = background:color;
      Mettre une image en arrière-fond = background: url(./image.png)

      Ajouter = norepaeat center/cover;

      Ou alors ajouter = min-height: 100vh
