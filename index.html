VSS

  • PLUGINS VSS CODE

    • Live server

      Activer "Auto Save : onWindowChange"

      Activer "World Wrap : on"

    • One Dark Pro

      Définir "Workbench: Color Theme : One Dark Pro"

    • Prettier - Code formatter

      Définir "Configure Default Formatter : Prettier - Code formatter"

      Cocher "Format On Save"

      Changer "Spaces" en 2 (Indent Using Sapces)

HTML

  • ICONE NAVIGATEUR

    Chercher logo HTML -> Images -> Outils -> Couleur -> Transparent

    Pour l'ajouter aller sous title -> taper link (link rel="stylesheet" href="") apparait -> remplacer "stylesheet" par "shortcut icon" et indiquer son chemin dans href="./..."

    Exemple: link rel="shortcut icon" href="./assets/img/logo.png"

  • LES DIFFERENTES PARTIES D'UN SITE

    Principales: nav header main footer

    Secondaires: section div span p i

  • UL = Unordered List -> liste sans numéro (avec des puces)

    Utilisation "UL" -> "LI" pour les élements à lister (possibilité d'utiliser li*# où # = nombres de répetitions de LI)

  • OL = Ordered List -> Liste avec des numéros

    Utilisation "OL" -> "LI" pour les élements à lister (possibilité d'utiliser li*# où # = nombres de répetitions de LI)

  • IMAGE EN HTML

    Utiliser "img" qui donne (img src="" alt="") indiquer son chemin dans src="./..." et indiquer une description dans alt="".

    Utilisation de height="200" par exemple est possible pour réduire sa taille en HTML

  • TYPE DE TEXTE

    Normal

    Italique balise "em"

    Gras balise "strong"

    Faux texte en latin "lorem#" où # = nombre de mots à ajouter

  • UTILISATION DES TABLEAUX

    Utilisation: table border="#" et "cellpading="#"" pour créer un espacement à l'intérieur des cellules et ajouter "cellspacing="#"" pour l'espacement entre cellules

    Exemple: table border="1" cellpadding="10" cellspacing="3" style="text-align: center"

    Utiliser "thead" pour l'entête du tableau Utiliser "tr" pour définir la ligne de l'entête Utiliser "th" pour chaque colonne de l'entête
    Utiliser "tbody" pour la suite du tableau Utiliser "tr" pour chaque ligne du tableau Utiliser "td" pour chaque colonne du tableau
    Utiliser "tfoot" pour le pied du tableau avec "tr" et "td" Utiliser "rowspan="#"" ou "colspan="#"" pour étendre une cellule

  • UTILISATION DES LIENS

    • Lien vers un autre site

      Taper "a" (pour ancre) remplir href="" et remplir par un texte entre les balises

      Utiliser "target="_blank"" pour ouvrir dans un nouvel onglet

      Exemple: dans les balises a: href="https://htmlcheatsheet.com/" target="_blank">HTML Cheat Sheet


      HTML Cheat Sheet

    • Lien vers une autre partie du site

      Créer un id à la section vers laquelle on veut créer un lien

      Utiliser une ancre a dans href="#id" où id est l'id est celui de la section désirée

    • Lien vers un Email

      utiliser l'ancre a avec dans href="mailto:adresse@domain.ext suivi du message du lien.

    • Lien vers un téléchargement

      utiliser l'ancre a avec href="./chemin" download="Nom du téléchargement" Télécharger la notice.

  • INTEGRATION DES VIDEOS

    • Vidéos et images gratuites et libres de droits -> https://pixabay.com/fr/

      Utiliser "Video" remplir la src:".//"

      Paramètres à utiliser: "autoplay" "muted" "loop" et éventuellement "height="200"

      Exemple: video src="./assets/video/video.mp4" height="200" autoplay muted

  • LES FORMULAIRES

    • Input de type text

      Délarer avec la balise "form" action="" peut rester libre pour l'instant.

      Ensuite déclarer un "label" avec for="id de l'input" suivi du texte a afficher.

      Déclarer enfin un "input" de type "text" par exemple et dans "id" utiliser la même chose que dans label pour lier les deux.

      On peut tuiliser un placeholder="entrez votre texte"

    • Input de type number

      Même chose que pour l'input text. On peut utiliser value="18" par exemple pour commecer avec un nombre.

    • Input de type select

      label idem que les autres types de formulaires

      Utilier select id puis à la ligne les options avec option value="Homme"

      Rajouter la banière selected pour l'option par défaut.

    • Input de type radio

      Copier le nombre de fois que nécessaire input et label avec le même name="type"

      On peut utiliser "checked" après id pour qu'il soit selcetionné par défaut.

    • Input de type textarea

      Pas besoin de name, on peut mettre une placeholder="votre message..." cols et row pour la taille

    • Input de type checkbox

      Faire correspondre id de l'input et for du label

    • Bouton pour valider

      input:submit dans value mettre le nom qui apparait sur le bouton.

GITHUB

  • Depuis le dossier de travail pour ouvrir VS Code depuis GitBash -> code .

  • Pour ajouter le travail en cours en local depuis GitBash -> git add .

  • Pour vérifier ce qui a été ajouté en local depuis GitBash -> git status

  • Pour sauvegarder en local la version en cours depuis GitBash -> git commit - m "explication"

  • Pour synchroniser les changements en cours sur GitHub depuis GitBash -> git push -u origin main
